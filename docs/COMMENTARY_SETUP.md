# Commentary setup

The public source repository does not contain commentary audio, disc images, or extracted game assets. A test package
may provide the launcher and setup tools, but each player must provide their own legally obtained source material.

## Core sources

The intended core commentary set is:

1. WWE SmackDown! Here Comes the Pain
2. WWE SmackDown! Shut Your Mouth
3. WWE SmackDown! vs. Raw (retail release)
4. WWE SmackDown! vs. Raw public beta

Additional sources such as SmackDown vs. Raw 2006/2007/2008, WWE 2K14, and Legends of WrestleMania are optional
supplements. They should add coverage when available; they are not required to boot or test the core HCTP path.

The launcher/setup workflow should validate user-supplied paths, build or install only derived local assets, and keep
source-game files outside the repository and outside any redistributed release archive.
